# 结构化 36 阶 oriented graph 反例

[US English](README.md) | [CN 中文说明](README_zh.md)

取六个互不相交的独立簇，大小为

```text
(11, 7, 3, 3, 3, 9)
```

簇间方向由以下六点 tournament 决定：

```text
0 -> 1,2,4
1 -> 3,4,5
2 -> 1,5
3 -> 0,2
4 -> 2,3,5
5 -> 0,3
```

所得 36 阶 oriented graph 没有任何 strong Seymour 顶点。六类根顶点分别
具有以下 Hall 缺陷：

| 根簇 | 选择的簇 | 可到达的严格二阶簇 | 权重 |
|---:|---|---|---:|
| 0 | 1,2,4 | 3,5 | 13 > 12 |
| 1 | 3,4,5 | 0,2 | 15 > 14 |
| 2 | 1 | 3,4 | 7 > 6 |
| 3 | 0 | 1,4 | 11 > 10 |
| 4 | 3,5 | 0 | 12 > 11 |
| 5 | 0,3 | 1,2,4 | 14 > 13 |

同一簇内的顶点具有相同邻域，因此六份证书覆盖全部 36 个顶点。把所有簇
大小同时乘以任意正整数，严格不等式仍然成立，从而得到阶数为
`36, 72, 108, ...` 的无限反例族。

一键复现：

```bash
bash run_all.sh
```

脚本重新编译 C++ 检查器，运行 Python、C++ 和第三套有限状态 DP 审计，
比较重新生成的完整 JSON 与发布文件，并检查固定哈希。若已安装 NetworkX，
还会自动进行额外交叉验证。

本目录只认证这个显式构造，不声称 36 是最小阶数，也不包含更大的加权模板
穷举。
