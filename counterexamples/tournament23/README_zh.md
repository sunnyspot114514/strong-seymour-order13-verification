# 一个经过验证的 23 阶 tournament 反例

[English](README.md) | [中文说明](README_zh.md)

本包给出一张 23 阶 tournament，其中不存在 strong Seymour 顶点。对每个
顶点 \(x\)，从 \(N^+(x)\) 到严格二阶出邻域 \(N^{++}(x)\) 的二部图都没有
饱和 \(N^+(x)\) 的匹配。

这把本仓库中的显式上界从 24 改进到了 23，但**尚未证明 23 是最小阶数**：
仍需完整排除 14 至 22 阶，或者找到更小反例。

## 反例

邻接矩阵位于
[`data/adjacency_matrix.txt`](data/adjacency_matrix.txt)，其中
\(A_{uv}=1\) 表示 \(u\to v\)。SHA-256 为：

```text
c6789b8adaf98b5d1da924a453243cad253d385263a7c08652f5bc7ff80f7612
```

出度序列为：

```text
10,12,11,10,11,11,12,12,10,11,11,10,11,13,11,10,12,11,11,10,11,12,10
```

独立计算的最大匹配数为：

```text
9,10,10,9,10,10,10,10,9,10,10,9,10,9,10,9,10,10,10,9,10,10,9
```

每个最大匹配数都严格小于对应出度，因此 23 个顶点全部不是 strong。

## 验证

包内包含两套实现方式明显不同的检查器：

- `src/verify.py` 使用有限状态动态规划精确求最大匹配，并穷举全部左侧
  子集寻找 Hall 缺陷；
- `src/verify.cpp` 使用 Kuhn 增广路算法，并再次独立穷举全部左侧子集。

逐顶点匹配数和显式 Hall 证书见
[`data/full_verification.json`](data/full_verification.json)。

在 Ubuntu/WSL 中运行：

```bash
./run_all.sh
```

脚本会检查哈希，从源码重新运行两套实现，并把重新生成的 JSON 与公开结果
逐字节比较。

## 发现方式和当前边界

该矩阵来自精确 SAT 编码的 \(d=10,p=4\) 可满足分支。这里 \(d\) 是规范根
顶点的最小出度，\(p\) 是该根的补齐至 \(d-1\) 个顶点的覆盖证书中位于
出邻域一侧的顶点数。

结合已经验证的 13 阶及以下正面结果，目前严格可写为：

\[
14\le n_{\min}\le 23.
\]

14 至 22 阶的精确搜索与反例声明分开记录；任何限时超时都只记为
`UNKNOWN`，不会被当作不存在性证明。
